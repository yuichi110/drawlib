# `_core` Layer & Release Assets Manifest Refactoring Plan

## 1. Background & Objectives

Following the `drawlib.graph` pure-layout refactoring and the relocation of `get_dimage_from_code` from `l3_images` to `l4_canvas`, this plan addresses the remaining architectural and code quality improvements inside the foundational `src/drawlib/_core/` layer (and its interaction with `src/drawlib/_release_assets.py`).

### Key Goals
1. **Preserve `_release_assets.py` at Top-Level with Explicit Docstring Guard & Deep Immutability**:
   - Explicitly document in `src/drawlib/_release_assets.py` (and its generator `tools/dcli/release_assets/sync.py`) that `_release_assets.py` is intentionally placed at the top level of `src/drawlib/` as a visible Single Source of Truth (SoT) definition table and **must not** be moved into `_core/`.
   - Enforce immutability (`Final`, `MappingProxyType`, frozen Pydantic models, `tuple[str, ...]`) for constant tables in `_release_assets.py`, `l1_core`, `l3_external`, and `l3_fonts`.
2. **Self-Contained `l1_core`**:
   - Remove `import drawlib._cached_assets` from `src/drawlib/_core/l1_core/_const.py` by resolving `ASSETS_DIR_PATH` relative to `__file__`, and annotate all `l1_core` constants with `Final[str]`.
3. **Unify `BaseColors` (`l3_colors`) with `BaseStyles` (`l3_styles`) on Strict PascalCase**:
   - Remove legacy lowercase `@property` accessors (`.primary`, `.secondary`, etc.) and lowercase `capitalize()` fallbacks (`Colors.red`, `Colors["red"]`) from `src/drawlib/_core/l3_colors/_colors.py`, matching `BaseStyles`.
   - Remove unused `typing` imports in `src/drawlib/_core/l3_colors/_colors.py`.
4. **Split Large Modules & Deduplicate Path Builders in `l4_canvas/_shapes/`**:
   - Split `src/drawlib/_core/l4_canvas/_shapes/_util.py` (950 lines) by extracting polygon/ellipse/hole path geometry builders into `src/drawlib/_core/l4_canvas/_shapes/_path_util.py` while keeping `ShapeUtil` as the unified facade.
   - Split `src/drawlib/_core/l4_canvas/_shapes/_arrow.py` (773 lines) by extracting `ArrowPolylineHelper` and arrow geometry builders into `src/drawlib/_core/l4_canvas/_shapes/_arrow_builders.py` (matching `_badge_builders.py`, `_container_builders.py`, `_symbol_builders.py`), and replace duplicate `_get_path_from_points` with `ShapeUtil.build_matplotlib_path`.
5. **Deduplicate `l4_canvas` Helpers & Eliminate All `# noqa: C901` in `_core`**:
   - Extract shared `xy_shift` / `xy_abs_shift` coordinate transformation (currently duplicated across `_text.py`, `_images.py`, and `_shapes/_util.py`) into a single helper, removing `# noqa: C901` from `CanvasImageFeature.image()`.
   - Refactor `CanvasBase.setup()` in `src/drawlib/_core/l4_canvas/_base.py` into private helper methods (`_setup_size_dpi`, `_setup_background`, `_setup_grid`) to remove `# noqa: C901`.
   - Deduplicate temporary grid rendering artist swap in `src/drawlib/_core/l4_canvas/_canvas.py` (`show`, `get_dimage`, `save`) and `FontProperties` construction in `src/drawlib/_core/l4_canvas/_text_util.py`.

## 2. Detailed Work Items

### Phase 1: `_release_assets.py` Docstring Guard & Immutable Constant Tables (`l1_core`, `l3_external`, `l3_fonts`)

1. **`tools/dcli/release_assets/sync.py` & `src/drawlib/_release_assets.py`**:
   - Add an explicit `Note:` / `Architectural Note:` block to the module docstring of `_release_assets.py` (generated by `sync.py`):
     > **Architectural Note (Do Not Move)**:
     > This file is intentionally placed at the top level of `src/drawlib/` as a human- and tool-visible Single Source of Truth (SoT) definition table for external release assets. Do **NOT** relocate or hide this module inside `drawlib._core` (`l1_core`, `l3_external`, etc.).
   - In `src/drawlib/_core/l3_external/_package.py`:
     - Change `ReleaseAssetPackage.files` from `list[str]` to `tuple[str, ...]` (Pydantic automatically coerces list inputs into immutable `tuple` on frozen models) so package definitions cannot be mutated in-place.
     - Add `model_config = ConfigDict(frozen=True)` to `AssetManifest`.
   - Re-run `./dcli release-assets sync` to regenerate `src/drawlib/_release_assets.py` and verify with `./dcli release-assets sync --check`.

2. **`src/drawlib/_core/l1_core/_const.py`**:
   - Replace `import drawlib._cached_assets` with `os.path.normpath(os.path.join(os.path.dirname(__file__), "..", "..", "_cached_assets"))`.
   - Type all constants (`LIB_NAME`, `LIB_VERSION`, `ASSETS_DIR_PATH`, `FONT_DIR_PATH`, `FONT_ICON_DIR_PATH`, `ICON_DIR_PATH`, `MAP_DIR_PATH`, `RULES_DIR_PATH`) as `Final[str]`.

3. **`src/drawlib/_core/l3_fonts/_resources.py`**:
   - Wrap `FONT_RESOURCES` in `types.MappingProxyType` with type `Final[Mapping[str, FontResource]]` so the font resource dictionary cannot be mutated at runtime.
   - Update `src/drawlib/_core/l3_styles/_base_styles.py` module constants (`DEFAULT_TEXT_SIZE`, `DEFAULT_FONT`, `DEFAULT_FONT_BOLD`, `DEFAULT_FONT_THIN`) to use `Final`.

### Phase 2: `l3_colors` (`BaseColors`) PascalCase Alignment & Cleanup

1. **`src/drawlib/_core/l3_colors/_colors.py`**:
   - Remove unused `typing` imports (`Callable`, `Concatenate`, `Generic`, `ParamSpec`, `TypeVar`, `overload`).
   - Remove the 11 legacy lowercase `@property` definitions (`primary`, `secondary`, `accent`, `muted`, `light`, `dark`, `canvas`, `danger`, `success`, `warning`, `neutral`).
   - Remove lowercase `capitalize()` fallback resolution in `_BaseColorsMeta` (`__getattribute__`, `__getattr__`, `__getitem__`), `BaseColors` (`__getitem__`, `__getattr__`), and `_resolve_color_field_name`, enforcing strict PascalCase (`Colors.Primary`, `Colors.Red`, `Colors.Transparent`) just like `BaseStyles`.
2. **`tests/drawlib/_core/l3_styles/test_preset_styles_access.py`**:
   - Update `TestPresetColorsPascalCaseAccess` to assert that PascalCase access (`DefaultColors.Red`, `DefaultColors.Primary`, `DefaultColors["Red"]`) succeeds and lowercase access (`DefaultColors.red`, `DefaultColors.primary`, `DefaultColors["red"]`) raises `AttributeError` / `KeyError`, matching `TestPresetStylesPascalCaseAccess`.

### Phase 3: `l4_canvas/_shapes/` Module Split & Deduplication

1. **Split `src/drawlib/_core/l4_canvas/_shapes/_util.py` (950 lines)**:
   - Create `src/drawlib/_core/l4_canvas/_shapes/_path_util.py` containing the pure path/polygon/hole geometry functions (`build_matplotlib_path`, `round_polygon_points`, `inset_convex_polygon`, `shrink_shape_r`, `build_ellipse_path`, `build_hollow_ellipse_path`, `arc_points_local`, `subpaths_to_compound_path`, `lighten_rgba`, `darken_rgba`, `resolve_feature_colors`).
   - Keep `ShapeUtil` in `_util.py` exposing all existing static methods (delegating to `_path_util.py`) so all callers and tests remain 100% compatible.
2. **Split `src/drawlib/_core/l4_canvas/_shapes/_arrow.py` (773 lines)**:
   - Create `src/drawlib/_core/l4_canvas/_shapes/_arrow_builders.py` containing `ArrowPolylineHelper` and arrow geometry calculation helpers.
   - Replace `CanvasShapeArrowFeature._get_path_from_points` with `ShapeUtil.build_matplotlib_path`.

### Phase 4: `l4_canvas` Deduplication & Zero `# noqa: C901`

1. **Unify `xy_shift` / `xy_abs_shift` Coordinate Shift Logic**:
   - Add `ShapeUtil.apply_xy_shift(xy: Coordinate, angle: float, style: Style) -> Coordinate` (or in `l4_canvas/_base.py`).
   - Reuse it in:
     - `src/drawlib/_core/l4_canvas/_text.py` (`CanvasTextFeature.text`)
     - `src/drawlib/_core/l4_canvas/_images.py` (`CanvasImageFeature.image`) — removing `# noqa: C901`
     - `src/drawlib/_core/l4_canvas/_shapes/_util.py` (`ShapeUtil.get_shape_text`)
2. **Eliminate `# noqa: C901` in `src/drawlib/_core/l4_canvas/_base.py`**:
   - Extract nested closures `config_size_dpi()`, `config_background()`, and `config_grid()` in `CanvasBase.setup()` into private methods `_setup_size_dpi()`, `_setup_background()`, and `_setup_grid()`, removing `# noqa: C901`.
3. **Deduplicate `Canvas` Grid Rendering & `TextUtil.get_font_properties`**:
   - In `src/drawlib/_core/l4_canvas/_canvas.py`, extract a helper method `_execute_with_grid(self, zorder: float, action: Callable[[], None]) -> None` used by `show()`, `get_dimage()`, and `save()`.
   - In `src/drawlib/_core/l4_canvas/_text_util.py`, extract `_build_font_properties_from_path(file_path: str, size: float) -> FontProperties` to eliminate duplicate `resolve_svg_font_info` -> `FontProperties` logic between `FontFile` and `FontBase`.

## 3. Verification Criteria

1. `./dcli release-assets sync --check` passes cleanly.
2. `./dcli code-check all` passes with 0 lint, format, type, or docstring errors, and **zero `# noqa: C901` comments in `src/drawlib/_core/`**.
3. `./dcli test target core` and `./dcli test all` pass 100%.
