Drawlib Python API

Declarative pure-Python API reference for Illustration as Code, technical diagrams, quantitative charts, and structured visual components. All public modules re-export type-checked symbols from drawlib.* with runtime @validate_call parameter validation.

Coordinate & Anchor Conventions#

Drawlib uses a standard mathematical Cartesian coordinate space where (0, 0) is strictly at the bottom-left corner, X increases rightward (0 to width), and Y increases upward (0 to height).

from drawlib.canvas import save, setup
from drawlib.shapes import rectangle
from drawlib.styles import Styles

setup(width=120, height=48)
rectangle((60, 24), width=44, height=20, style=Styles.Neutral, text="Centered at (60, 24)")
save("service_card.png")
Component Family Coordinate Parameter Anchor Reference Point
drawlib.shapes, text, icons, images xy=(cx, cy) Center of bounding box
drawlib.diagrams.*, drawlib.charts.* draw(xy=(x0, y0)) Bottom-Left corner (align="center" optional)
Table, TreeNode, BulletPoints, SourceCode draw(xy=(x0, y_top)) Top-Left corner (grows downward)

Runtime Validation#

All public drawing functions and component methods are decorated with @validate_call (powered by Pydantic v2). Passing out-of-range dimensions (width <= 0), invalid color tuples, or unknown literal options raises a structured ValidationError immediately at call time before rendering.

Common Validated Parameter Types
Parameter Pattern Accepted Python Types Constraints
xy, xy1, xy2 tuple[float, float] Finite (x, y) Cartesian coordinates
width, height, radius float Strictly positive (> 0.0)
alpha, background_alpha float Normalized opacity in [0.0, 1.0]
background_color Color | tuple[int, int, int] | str Colors.* token, RGB/RGBA tuple, or #RRGGBB hex
