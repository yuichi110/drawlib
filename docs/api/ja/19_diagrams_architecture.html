drawlib.diagrams.architecture（アーキテクチャ構成図）

アイコン付きサービスカード、ネスト可能な境界グループ、直交バスルーティングを備えた、クラウド・インフラ・分散システム向けの宣言的アーキテクチャ構成図モジュールです。標準インポート: from drawlib.diagrams.architecture import ArchitectureDiagram, Edge, GcpIcon, Junction, Node, NodeGroup, PhosphorIcon。

Source Code 
from drawlib.canvas import save, setup
from drawlib.diagrams.architecture import ArchitectureDiagram, GcpIcon, Node, NodeGroup, PhosphorIcon
from drawlib.styles import Colors, Styles

setup(width=124, height=64)

d = ArchitectureDiagram(
    node_style=Styles.Primary,
    node_text_style=Styles.DarkBold.patch(text_size=10.5),
    edge_style=Styles.DarkBold,
    edge_text_style=Styles.Dark.patch(text_size=10.0),
    node_card_style=Styles.Neutral,
)

client = d.add(
    Node("Client", width=18, height=16, icon=PhosphorIcon.LAPTOP, icon_size=7.0),
    xy=(9.0, 25.0),
)

vpc = d.add(
    NodeGroup(
        title="VPC Network",
        width=60,
        height=54,
        padding=5.0,
        style=Styles.PrimaryNeutral.patch(line_style="dashed"),
        text_style=Styles.PrimaryBold.patch(text_size=11.0, halign="left"),
    ),
    xy=(30.0, 0.0),
)
gateway = vpc.add(
    Node(
        "API Gateway",
        width=20,
        height=16,
        icon=PhosphorIcon.CLOUD_CHECK,
        icon_size=6.5,
        style=Styles.White,
        text_style=Styles.WhiteBold.patch(text_color=Colors.White, text_size=10.5),
        card_style=Styles.PrimaryFlat,
    ),
    xy=(13.5, 25.0),
)
auth_pod = vpc.add(
    Node("Auth Pod", width=19, height=15, icon=GcpIcon.GOOGLE_KUBERNETES_ENGINE, icon_size=6.5),
    xy=(47.0, 36.5),
)
order_pod = vpc.add(
    Node(
        "Order Pod",
        width=19,
        height=15,
        icon=GcpIcon.GOOGLE_KUBERNETES_ENGINE,
        icon_size=6.5,
        card_style=Styles.SecondaryNeutral,
    ),
    xy=(47.0, 13.5),
)

db = d.add(
    Node("Cloud SQL", width=20, height=16, icon=GcpIcon.CLOUD_SQL, icon_size=7.0, card_style=Styles.SecondaryNeutral),
    xy=(106.5, 25.0),
)

d.connect(client, gateway, label="HTTPS", padding=1.0)
gateway.fork([auth_pod, order_pod], at_x=57.5, padding=1.0)
d.connect(auth_pod, db, padding=1.0)
d.connect(order_pod, db, padding=1.0)

d.draw(xy=(62.0, 32.0), align="center")
save()

classArchitectureDiagram#

サービスノード、ネストされた境界グループ、ジャンクション（分岐・合流点）、およびエッジルーティングを統合管理するアーキテクチャ構成図のトップレベルコンテナです。

ArchitectureDiagram(
    *,
    node_style: Style,
    node_text_style: Style,
    edge_style: Style,
    edge_text_style: Style,
    node_card_style: Style | None = None,
    title: str = "",
    title_style: Style | None = None,
    width: float | None = None,
    height: float | None = None,
    style: Style | None = None,
) -> None
  • 座標アンカー: draw(xy=(0.0, 0.0), align="bottom_left") は図のローカル左下原点 (0.0, 0.0) をキャンバス座標 xy に配置します（align="center" の場合は図全体のバウンディングボックス中心を xy に配置）。自動トポロジ座標計算については ArchitectureGraph.get_layout() を参照してください。

コンストラクタ引数#

引数 型 デフォルト 説明
node_style Style (必須) ベクターアイコンの着色やフォールバック図形に適用される基本スタイル（キーワード専用）。
node_text_style Style (必須) ノードラベルおよびグループ見出しに適用される基本テキストスタイル（キーワード専用）。
edge_style Style (必須) 接続エッジの線と矢印に適用される基本スタイル（キーワード専用）。
edge_text_style Style (必須) エッジラベルに適用される基本テキストスタイル（キーワード専用）。
node_card_style Style | None None Node カードのデフォルト背景・枠線スタイル（None の場合は背景透過）。
title str "" 図の上部中央に描画される任意のタイトル文字列。
title_style Style | None None title 用の任意のテキストスタイル上書き。
width float | None None ローカル単位での固定幅（None の場合は登録要素から自動算出）。
height float | None None ローカル単位での固定高さ（None の場合は登録要素から自動算出）。
style Style | None None 図全体を囲む外枠カードの任意の背景・枠線スタイル。

パブリックメソッド・プロパティ#

メンバー 種別 シグネチャ 説明
add method (self, item: ItemT, xy: tuple[float, float], *, show: bool | None = None) -> ItemT 図のローカル座標 xy に Node（中心 xy）、NodeGroup（左下 xy）、または Junction を登録します。
add_edge method (self, edge: Edge, *, show: bool | None = None) -> Edge 構築済みの Edge インスタンスを図に登録します。
connect method (self, start: Connectable, end: Connectable, label: str = "", arrow: ArrowType = "->", routing: RoutingType = "orthogonal", style: Style | None = None, text_style: Style | None = None, padding: PaddingType = 0.0, show: bool = True) -> Edge 任意の接続可能要素（Node、NodeGroup、Junction）間に Edge を生成して登録します。
draw method (self, xy: tuple[float, float] = (0.0, 0.0), *, align: Literal["bottom_left", "center"] = "bottom_left", scale: PosFloat = 1.0) -> None アクティブなキャンバス上のアンカー xy にアーキテクチャ構成図を描画します。
edges property -> list[Edge] 登録された Edge のリストを宣言順で返します。
get_size method (self) -> tuple[float, float] スケール適用前のローカル単位での図全体の (width, height) を返します。
items property -> list[Node | NodeGroup | Junction] 図直下に登録されたトップレベル要素のリストを返します。
junction method (self, xy: tuple[float, float], *, show: bool = True) -> Junction ローカル座標 xy に面積ゼロの中継・分岐点 Junction を生成・登録します。

classNode#

アーキテクチャ構成図内のサービス、アクター、コンピュートインスタンス、マネージドテスト・DB リソースを表すノードカード要素です。

Node(
    text: str = "",
    width: float = 20.0,
    height: float = 16.0,
    icon: IconType = None,
    icon_size: float = 8.0,
    style: Style | None = None,
    text_style: Style | None = None,
    card_style: Style | None = None,
    show: bool = True,
) -> None
  • 座標アンカー: 中心 (cx, cy)。d.add(node, xy=(cx, cy)) では図ルート座標、group.add(node, xy=(lx, ly)) では親 NodeGroup の左下 (0, 0) からのグループ相対中心座標で指定します。

コンストラクタ引数#

引数 型 デフォルト 説明
text str "" カード下部に描画される表示ラベル（\n による複数行改行に対応）。
width float 20.0 カードのバウンディングボックス幅（ローカル単位）。
height float 16.0 カードのバウンディングボックス高さ（ローカル単位）。
icon IconType None 34 種類のアイコン列挙型、アイコン描画関数（drawlib.icons.*）、CustomIcon、Dimage、PIL.Image.Image、または画像パス（str | Path）。
icon_size float 8.0 描画されるアイコンの幅・高さ（ローカル単位）。
style Style | None None ベクターアイコン着色用のスタイル上書き（未指定時は diagram.node_style）。
text_style Style | None None text ラベル用のテキストスタイル上書き（未指定時は diagram.node_text_style）。
card_style Style | None None カード背景・枠線のスタイル上書き（未指定時は diagram.node_card_style）。
show bool True 表示フラグ（False の場合、レイアウト座標を維持したままノードと接続エッジを非表示化）。

パブリックメソッド・プロパティ#

メンバー 種別 シグネチャ 説明
bottom property -> tuple[float, float] 図ルート座標系におけるカード下辺中央のアンカー座標。
center property -> tuple[float, float] 図ルート座標系におけるカード中心座標。
connect method (self, target: Connectable, label: str = "", arrow: ArrowType = "->", routing: RoutingType = "orthogonal", style: Style | None = None, padding: PaddingType = 0.0, show: bool = True) -> Edge このノードから target への Edge を生成し、親の図に登録します。
fork method (self, targets: list[Connectable], at_x: float | None = None, at_y: float | None = None, style: Style | None = None, padding: PaddingType = 0.0, show: bool = True) -> list[Edge] at_x または at_y に配置した直交 Junction を経由して複数の targets へファンアウト接続します。
get_absolute_xy method (self) -> tuple[float, float] ネストされた親 NodeGroup 階層を辿り、図ルート基準の絶対中心座標 (x, y) を算出します。
get_bounds method (self) -> tuple[float, float, float, float] ノード中心 (0, 0) 基準のローカル境界 (-width/2, -height/2, width/2, height/2) を返します。
get_size method (self) -> tuple[float, float] カードの (width, height) を返します。
left property -> tuple[float, float] 図ルート座標系におけるカード左辺中央のアンカー座標。
right property -> tuple[float, float] 図ルート座標系におけるカード右辺中央のアンカー座標。
top property -> tuple[float, float] 図ルート座標系におけるカード上辺中央のアンカー座標。
xy property -> tuple[float, float] 親コンテナへの登録時に指定された相対中心座標 (x, y)。

classNodeGroup#

Node カード、Junction、およびネストされたサブグループを束ねる階層的境界コンテナです（クラウドリージョン、VPC、サブネット、Kubernetes クラスタ等の表現に最適）。

NodeGroup(
    title: str = "",
    width: float | None = None,
    height: float | None = None,
    padding: float = 5.0,
    style: Style | None = None,
    text_style: Style | None = None,
    show: bool = True,
) -> None
  • 座標アンカー: 左下 (x0, y0)。group.add(child, xy=(lx, ly)) に渡す座標 (lx, ly) は、その group 自身の左下隅 (0, 0) を基準とするグループ相対座標になります（子要素が Node なら中心、ネストされた NodeGroup なら左下）。

classEdge#

2 つの接続可能要素（Node、NodeGroup、Junction）を結ぶ単方向・双方向・無方向の接続エッジです。

Edge(
    start: Connectable,
    end: Connectable,
    label: str = "",
    arrow: ArrowType = "->",
    routing: RoutingType = "orthogonal",
    style: Style | None = None,
    text_style: Style | None = None,
    padding: PaddingType = 0.0,
    show: bool = True,
) -> None
  • 座標アンカー: start と end の外周境界アンカーに自動接続されます。.points()、.via()、.add_point() に渡す中間ウェイポイントは図ルート座標系 (x, y) を使用します。
