# HTML Documentation

This directory contains self-contained HTML documentation compiled by **Drawlib**.

---

## 1. How to Open & View

- **Direct Browser Open (Zero Dependencies)**:
  Double-click or open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari). No Python, Drawlib, or web server is required.
- **Local HTTP Server (Optional)**:
  ```bash
  python3 -m http.server 8000
  ```

---

## 2. Viewing & Navigation

- **Linear Documents (`doc`)**:
  All chapters are combined into `index.html` in reading order with visual chapter dividers and a **Table of Contents** for instant jumping.
- **Multi-Page Documentation Sites (`site`)**:
  Use the left sidebar navigation to move between pages. All page links, stylesheets, and images use relative paths and work directly from local folders (`file://`).
- **Animated Diagrams**:
  Embedded APNG (`.png`) and Animated WebP (`.webp`) illustrations play and loop automatically in the browser.
