BoxList（ボックスリスト）

BoxList コンポーネントは、水平軸または垂直軸に沿って隙間なく連続する矩形カード列を描画します。 カスタムスタイルを指定した要素は自動的に第 2 パスで描画されるため、隣接するデフォルトボックスの上に枠線がきれいに重なり、メモリ／パケット構造、ステージシーケンス、垂直方向の機能スタックの表現に最適です。

1. 基本概念と基本的な使い方

BoxList は .add(...) によって隙間なく連続する矩形セル列を構築し、デフォルトで複数ボックス全体のバウンディングボックスの左下角 (x, y)（align="center" の場合は中央）を基準に配置します。4 つの軸方向（"left", "right", "bottom", "top"）への展開、カスタム強調枠が隣接エッジ上にきれいに重なる自動 2 パス Z オーダー描画、および他のスロット位置をずらさない .items[i] の非表示化やスケーリングに対応しています。

def draw_step_bar(active_part: int) -> None:
    """Draw top 4-part progress bar (active_part is 1..4)."""
    pill_w = 31.0
    pill_h = 7.4
    gap = 2.0
    start_x = 4.0 + pill_w / 2.0
    cy = 75.2

    for idx, (label, sublabel) in enumerate(PART_ITEMS, start=1):
        cx = start_x + (idx - 1) * (pill_w + gap)
        if idx > 1:
            prev_cx = cx - (pill_w + gap)
            line(
                (prev_cx + pill_w / 2.0 + 0.2, cy),
                (cx - pill_w / 2.0 - 0.2, cy),
                style=Styles.PrimaryBold if idx <= active_part else Styles.MutedThin,
            )

        if idx == active_part:
            st = Styles.PrimaryFlat.patch(shape_r=1.4)
            tst = Styles.WhiteBold.patch(text_size=10.3)
            sub_tst = Styles.White.patch(text_size=9.5)
        elif idx < active_part:
            st = Styles.PrimaryNeutral.patch(shape_r=1.4, shape_line_width=1.1)
            tst = Styles.PrimaryBold.patch(text_size=10.3)
            sub_tst = Styles.Primary.patch(text_size=9.5)
        else:
            st = Styles.Neutral.patch(shape_r=1.4, shape_line_width=1.1)
            tst = Styles.MutedBold.patch(text_size=10.3)
            sub_tst = Styles.Muted.patch(text_size=9.5)

        rectangle((cx, cy), width=pill_w, height=pill_h, style=st)
        text((cx, cy + 1.35), label, style=tst)
        text((cx, cy - 1.55), sublabel, style=sub_tst)

            shape_line_color=(203, 213, 225),

            shape_r=2.4,
        ),
        text=footer_caption,
        text_style=Styles.DarkBold.patch(text_size=9.8),
    )
    return sheet_cx, sheet_cy

save()
  • 隙間なしの連続構築とアンカー（.add(), xy）: ボックスを順に追加することで、デフォルトで左下 xy を基準とする正確な N * box_width 幅の隙間なしシーケンスを構築します。
  • 4 つの軸方向（direction）: "left"（+X、デフォルト）または "right"（-X）による水平フロー、および "bottom"（上方向 +Y）または "top"（下方向 -Y）による垂直スタックに対応します。
  • 2 パスのハイライト Z オーダー（style の個別上書き）: BoxList.draw() はデフォルトスタイルのセルを第 1 パスで、カスタムスタイルの強調セルを第 2 パスで描画するため、太枠や PrimaryFlat の境界線が隣接ボックスとの共有エッジ上に重なり、途切れず鮮明に表示されます。
  • スロット位置を維持する .show・scale・align="center": bl.items[i].show = False で隣接座標をずらさずに特定のボックスを非表示にできるほか、scale で xy 基準の拡大縮小、align="center" で全体領域の (cx, cy) 中央配置を行えます。

2. 注目ステージを強調した水平シーケンス（direction="left"）

direction="left"（デフォルト）の場合、ボックスは xy=(x, y) を起点として右方向（+x）へ水平に並びます。複数の BoxList インスタンスを矢印やラベルと組み合わせることで、処理パイプラインやパケット構造をわかりやすく図解できます。

4. レイアウト方向・アンカー位置・2 パス Z オーダー

ページ冒頭の図解に示されているとおり、配置方向と描画順は以下の規則に従います。

  • レイアウト方向（direction）:
    • "left" （デフォルト）: バウンディングボックスの左端から右方向（+x）へボックスを並べます。
    • "right": バウンディングボックスの右端から左方向（-x）へボックスを並べます。
    • "bottom": バウンディングボックスの下端から上方向（+y）へボックスを積み上げます。
    • "top": バウンディングボックスの上端から下方向（-y）へボックスを積み下げます。
  • アンカー基準位置（align）:
    • "bottom_left" （デフォルト）: xy は BoxList 全体のバウンディングボックスの左下角を指定します。
    • "center": xy は BoxList 全体のバウンディングボックスの中央を指定します。
  • 2 パス強調 Z オーダー: BoxList.draw() はデフォルトスタイルのボックスを第 1 パスで描画し、カスタムスタイルを持つボックスを第 2 パスで描画するため、強調表示した枠線が隣接するニュートラルなボックスに隠れてしまうことはありません。

5. API リファレンス

コンストラクタ

BoxList(
    *,
    style: Style,
    text_style: Style,
)

メソッドとプロパティ

  • add(text: str, *, style: Style | None = None, text_style: Style | None = None, show: bool = True) -> BoxListItem: シーケンスの末尾にボックス要素を追加し、変更可能な BoxListItem（text, style, text_style, show）を返します。show=False を設定すると、後続のすべてのボックスの位置を変えずに該当ボックスのみを非表示にします。
  • boxlist.items -> list[BoxListItem]: 登録済みのすべての BoxListItem インスタンスのリスト（text: str, style: Style, text_style: Style, show: bool）を返します。draw() の呼び出し前や複数回の呼び出し間でプロパティを事後変更できます。
  • draw(xy: tuple[float, float], box_width: float, box_height: float, direction: Literal["left", "right", "bottom", "top"] = "left", align: Literal["bottom_left", "center"] = "bottom_left", scale: float = 1.0) -> None: xy（左下角または中央）を基準にボックス列を描画します。scale による比例スケーリングも指定できます。
