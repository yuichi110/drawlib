BulletPoints（箇条書きボード）

BulletPoints コンポーネントは、左上のアンカー座標 (x, y) を起点として多段階にネストされた箇条書きリストを描画します。 インデント幅や行間隔のカスタマイズ、階層レベルごとの図形・アイコン記号の指定、さらにレイアウト座標を維持したままの表示・非表示の切り替えに対応しています。

1. 基本概念と基本的な使い方

BulletPoints は、左上 xy=(x, y) を起点として多段階の箇条書きリストを構築し、後続の行を下方向 -Y へ vertical_margin ずつ送り、ネストした階層を右方向 +X へ indent_width * indent 分だけインデントします。set_indent(0..2) による階層深さの切り替え、set_bullet_style(...) による幾何学記号からベクターアイコンへの置き換え、さらに draw(...) を呼び出す前の個別 BulletPointItem のスタイル変更やレイアウトを崩さない非表示化（show=False）に対応しています。

def draw_step_bar(active_part: int) -> None:
    """Draw top 4-part progress bar (active_part is 1..4)."""
    pill_w = 31.0
    pill_h = 7.4
    gap = 2.0
    start_x = 4.0 + pill_w / 2.0
    cy = 75.2

    for idx, (label, sublabel) in enumerate(PART_ITEMS, start=1):
        cx = start_x + (idx - 1) * (pill_w + gap)
        if idx > 1:
            prev_cx = cx - (pill_w + gap)
            line(
                (prev_cx + pill_w / 2.0 + 0.2, cy),
                (cx - pill_w / 2.0 - 0.2, cy),
                style=Styles.PrimaryBold if idx <= active_part else Styles.MutedThin,
            )

        if idx == active_part:
            st = Styles.PrimaryFlat.patch(shape_r=1.4)
            tst = Styles.WhiteBold.patch(text_size=10.3)
            sub_tst = Styles.White.patch(text_size=9.5)
        elif idx < active_part:
            st = Styles.PrimaryNeutral.patch(shape_r=1.4, shape_line_width=1.1)
            tst = Styles.PrimaryBold.patch(text_size=10.3)
            sub_tst = Styles.Primary.patch(text_size=9.5)
        else:
            st = Styles.Neutral.patch(shape_r=1.4, shape_line_width=1.1)
            tst = Styles.MutedBold.patch(text_size=10.3)
            sub_tst = Styles.Muted.patch(text_size=9.5)

        rectangle((cx, cy), width=pill_w, height=pill_h, style=st)
        text((cx, cy + 1.35), label, style=tst)
        text((cx, cy - 1.55), sublabel, style=sub_tst)

def draw_geometry_studio(param_badge: str, footer_caption: str) -> tuple[float, float]:
    """Draw right geometry lab shell, inner coordinate sheet with subtle grid, and footer."""
    x0, w = 70.0, 64.0
    cx = x0 + w / 2.0
    top_y = 63.2
    header_h = 5.4
    body_h = 59.6

    rectangle((cx, top_y + header_h / 2.0), width=w, height=header_h, style=PANE_HEADER)
    phosphor.ruler((x0 + 3.6, top_y + header_h / 2.0), width=3.4, style=Styles.Primary)
    text(
        (x0 + 6.5, top_y + header_h / 2.0),
        "Live Geometry & Guides",
        style=Styles.DarkBold.patch(text_size=10.2, halign="left"),
    )
    text(
        (x0 + w - 2.6, top_y + header_h / 2.0),
        param_badge,
        style=Styles.PrimaryBold.patch(text_size=9.6, halign="right"),
    )

    rectangle((cx, 3.6 + body_h / 2.0), width=w, height=body_h, style=STUDIO_BODY)

    sheet_cx, sheet_cy = cx, 35.0
    sheet_w, sheet_h = 54.0, 40.0
    sx0, sy0 = sheet_cx - sheet_w / 2.0, sheet_cy - sheet_h / 2.0
    rectangle(
        (sheet_cx, sheet_cy),
        width=sheet_w,
        height=sheet_h,
        style=Styles.Neutral.patch(
            shape_fill_color=(255, 255, 255),
            shape_line_color=(180, 194, 214),
            shape_line_width=1.2,
        ),
    )
    g_st = Styles.MutedThin.patch(line_color=(232, 238, 246), line_width=0.8)
    for gx in range(1, 6):
        vx = sx0 + gx * (sheet_w / 6.0)
        line((vx, sy0), (vx, sy0 + sheet_h), style=g_st)
    for gy in range(1, 5):
        vy = sy0 + gy * (sheet_h / 5.0)
        line((sx0, vy), (sx0 + sheet_w, vy), style=g_st)

    rectangle(
        (cx, 8.4),
        width=59.2,
        height=5.2,
        style=Styles.Neutral.patch(
            shape_fill_color=(255, 255, 255),
            shape_line_color=(203, 213, 225),
            shape_line_width=1.1,
            shape_r=2.4,
        ),
        text=footer_caption,
        text_style=Styles.DarkBold.patch(text_size=9.8),
    )
    return sheet_cx, sheet_cy


def draw_sub_pills(scx: float, labels: list[str], active_idx: int) -> None:

    pw, ph, pgap = 17.2, 4.2, 1.2
    p_start = scx - (3 * pw + 2 * pgap) / 2.0 + pw / 2.0
    for idx, lbl in enumerate(labels):

        if idx == active_idx:
            pst = Styles.PrimaryFlat.patch(shape_r=1.2)
            ptst = Styles.WhiteBold.patch(text_size=9.5)

            pst = Styles.PrimaryNeutral.patch(shape_r=1.2, shape_line_width=1.0)
            ptst = Styles.PrimaryBold.patch(text_size=9.5)
        else:
            pst = Styles.Neutral.patch(shape_r=1.2, shape_line_width=1.0)
            ptst = Styles.Muted.patch(text_size=9.5)
        rectangle((px, 59.1), width=pw, height=ph, style=pst, text=lbl, text_style=ptst)

  • 左上原点と行送り間隔（xy, vertical_margin）: 1 行目の垂直ベースラインとレベル 0 の左端を xy=(x, y) に固定し、後続の項目を下方向 -Y へ vertical_margin ずつ配置します。
  • 多段階インデント（set_indent, indent_width）: 項目のテキストを右方向 x + indent_width * indent へシフトし、組み込み記号（0 = 記号なし見出し、1 = 塗りつぶし円、2 = 白抜き円）を描画します。
  • カスタムベクター記号（set_bullet_style）: 任意の正の indent_level におけるデフォルトの幾何学図形を、x + indent_width * (indent - 0.5) を中心とする phosphor.* アイコンや図形プリミティブに置き換えます。
  • 項目別スタイル上書き・スロット維持型非表示・スケーリング（items, show, scale）: 項目ごとの text_style の変更や、下方の項目をずらさずに非表示化する bp.items[i].show = False の切り替えに加え、draw(xy, scale=...) による xy 基準の等倍スケーリングをサポートします。

4. 座標とインデントの仕組み

  • 左上アンカー (x, y): bp.draw(xy=...) に渡す xy 座標は、1 行目の左端および垂直中心（y）を指定します。2 行目以降の項目は vertical_margin ずつ下方向へステップします（y - i * vertical_margin）。
  • インデントの幾何配置:
    • インデントレベル indent の項目のテキストは x_text = x + indent_width * indent から開始します。
    • indent != 0 かつ indent に箇条書き記号スタイルが登録されている場合、記号の中心は x_marker = x + indent_width * (indent - 0.5) に配置されます。
  • デフォルトの箇条書き記号:
    • indent = 0: 記号なし（リストのタイトルやセクション見出しに最適）。
    • indent = 1: text_style.text_color と同色の塗りつぶし円（radius=0.5）。
    • indent = 2: text_style.text_color と同色の白抜き円（radius=0.5）。

5. API リファレンス

コンストラクタ

BulletPoints(
    *,
    text_style: Style,
    vertical_margin: float,
    indent_width: float,
)

メソッドとプロパティ

  • set_indent(level: int) -> None: 以降の add() 呼び出しに適用される現在のインデントレベル（0, 1, 2, ...）を設定します。
  • set_bullet_style(indent_level: int, function: Callable, style: Style, args: dict) -> None: 指定した indent_level に対してカスタム描画関数（rectangle、circle、または任意の phosphor.* アイコン関数など）を登録します。描画時には function(xy=(x_marker, y), style=style, **args) が呼び出されます。
  • add(text: str, *, text_style: Style | None = None, show: bool = True) -> BulletPointItem: 現在のインデントレベルで箇条書き項目を追加し、変更可能な BulletPointItem（indent: int, text: str, text_style: Style, show: bool）を返します。なお、BulletPointItem.text_style の変更可能なプロパティエイリアスとして BulletPointItem.style も提供されています。show=False を設定すると、後続行の垂直スペースを保持したまま記号とテキストを非表示にします。
  • bp.items -> list[BulletPointItem]: 登録済みのすべての BulletPointItem インスタンスのリストを返します。draw() 呼び出しの前や呼び出し間で .text、.text_style（または .style）、.indent、.show を後から変更できます。
  • draw(xy: tuple[float, float], scale: float = 1.0) -> None: 表示状態のすべての箇条書き項目を xy を起点として描画します。scale による等倍スケーリングにも対応しています。
