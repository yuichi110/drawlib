GridLayout（グリッドレイアウト）

GridLayout コンポーネントは、均等または可変サイズの列・行マトリクス上にカードや矩形ブロックを配置します。 複数列・複数行にまたがるセル結合スパン、外枠コンテナ境界線、比例スケーリングを備えており、多層システムアーキテクチャ、サービスマトリクス、エグゼクティブダッシュボードのレイアウトに最適です。

1. 基本概念と基本的な使い方

GridLayout は、デフォルトで左下角 (x, y)（align="bottom_left"）または中央（align="center"）を基準とする、0 始まりのボトムアップ (col, row) マトリクス上にカードを配置します。.add((col, row), width, height, ...) で追加したセルは複数列・複数行への結合スパンが可能で、outer_style コンテナ内での均等配置や draw_flexible(...) による任意比率配置、さらに他のセルの座標をずらさない .items[i].show = False の切り替えに対応しています。

def draw_step_bar(active_part: int) -> None:
    """Draw top 4-part progress bar (active_part is 1..4)."""
    pill_w = 31.0
    pill_h = 7.4
    gap = 2.0
    start_x = 4.0 + pill_w / 2.0
    cy = 75.2

    for idx, (label, sublabel) in enumerate(PART_ITEMS, start=1):
        cx = start_x + (idx - 1) * (pill_w + gap)
        if idx > 1:
            prev_cx = cx - (pill_w + gap)
            line(
                (prev_cx + pill_w / 2.0 + 0.2, cy),
                (cx - pill_w / 2.0 - 0.2, cy),
                style=Styles.PrimaryBold if idx <= active_part else Styles.MutedThin,
            )

        if idx == active_part:
            st = Styles.PrimaryFlat.patch(shape_r=1.4)
            tst = Styles.WhiteBold.patch(text_size=10.3)
            sub_tst = Styles.White.patch(text_size=9.5)
        elif idx < active_part:
            st = Styles.PrimaryNeutral.patch(shape_r=1.4, shape_line_width=1.1)
            tst = Styles.PrimaryBold.patch(text_size=10.3)
            sub_tst = Styles.Primary.patch(text_size=9.5)
        else:
            st = Styles.Neutral.patch(shape_r=1.4, shape_line_width=1.1)
            tst = Styles.MutedBold.patch(text_size=10.3)
            sub_tst = Styles.Muted.patch(text_size=9.5)

        rectangle((cx, cy), width=pill_w, height=pill_h, style=st)
        text((cx, cy + 1.35), label, style=tst)
        text((cx, cy - 1.55), sublabel, style=sub_tst)

def draw_geometry_studio(param_badge: str, footer_caption: str) -> tuple[float, float]:
    """Draw right geometry lab shell, inner coordinate sheet with subtle grid, and footer."""
    x0, w = 70.0, 64.0
    cx = x0 + w / 2.0
    top_y = 63.2
    header_h = 5.4
    body_h = 59.6

    rectangle((cx, top_y + header_h / 2.0), width=w, height=header_h, style=PANE_HEADER)
    phosphor.ruler((x0 + 3.6, top_y + header_h / 2.0), width=3.4, style=Styles.Primary)
    text(
        (x0 + 6.5, top_y + header_h / 2.0),
        "Live Geometry & Guides",
        style=Styles.DarkBold.patch(text_size=10.2, halign="left"),
    )
    text(
        (x0 + w - 2.6, top_y + header_h / 2.0),
        param_badge,
        style=Styles.PrimaryBold.patch(text_size=9.6, halign="right"),
    )

    rectangle((cx, 3.6 + body_h / 2.0), width=w, height=body_h, style=STUDIO_BODY)

    sheet_cx, sheet_cy = cx, 36.2
    sheet_w, sheet_h = 54.0, 40.0
    sx0, sy0 = sheet_cx - sheet_w / 2.0, sheet_cy - sheet_h / 2.0
    rectangle(
        (sheet_cx, sheet_cy),
        width=sheet_w,
        height=sheet_h,
        style=Styles.Neutral.patch(
            shape_fill_color=(255, 255, 255),
            shape_line_color=(180, 194, 214),
            shape_line_width=1.2,
        ),
    )
    g_st = Styles.MutedThin.patch(line_color=(232, 238, 246), line_width=0.8)
    for gx in range(1, 6):
        vx = sx0 + gx * (sheet_w / 6.0)
        line((vx, sy0), (vx, sy0 + sheet_h), style=g_st)
    for gy in range(1, 5):
        vy = sy0 + gy * (sheet_h / 5.0)
        line((sx0, vy), (sx0 + sheet_w, vy), style=g_st)

    rectangle(
        (cx, 8.4),
        width=59.2,
        height=5.2,
        style=Styles.Neutral.patch(
            shape_fill_color=(255, 255, 255),
            shape_line_color=(203, 213, 225),
            shape_line_width=1.1,
            shape_r=2.4,
        ),
        text=footer_caption,
        text_style=Styles.DarkBold.patch(text_size=9.8),
    )
    return sheet_cx, sheet_cy

            ptst = Styles.Muted.patch(text_size=9.5)
        rectangle((px, 52.0), width=pw, height=ph, style=pst, text=lbl, text_style=ptst)

save()
  • ボトムアップの (col, row) マトリクス（xy, num_column, num_row）: デフォルトで左下 xy を基準に配置され（align="bottom_left"）、col = 0 が左端から右方向（+X）、row = 0 が下端から上方向（+Y）へ進みます。
  • 複数セルの結合スパン（.add((col, row), width, height)）: 右方向へ width 列、上方向へ height 行を内部の余白（ガター）ごとシームレスに結合し、バナーヘッダー、サイドバー、複数スロットにまたがるコア領域を構成できます。
  • 外枠コンテナと可変トラック（outer_style, draw_flexible）: outer_style を渡してマトリクス全体をパディング付きコンテナカードで囲むほか、明示的な column_widths・column_margins・row_heights・row_margins を指定した draw_flexible(...) による非対称レイアウトに対応します。
  • スロット位置を維持した非表示化と中央配置（items[i].show, align="center"）: grid.items[i].show = False を設定するとマトリクス座標をずらさずに特定のセルを非表示にでき、align="center" を渡すとグリッド全体を xy の中央に配置できます。

2. 複数セル結合によるアーキテクチャ・ダッシュボードレイアウト（draw）

標準モード（grid.draw(...)）では、全体の width と height を均一な margin（ガター間隔）で num_column 列 × num_row 行へと均等分割します。outer_style を指定した場合は外周コンテナ枠が描画され、四辺の外周にも同じ内側マージンが確保されます。

3. 可変グリッドサイズとカスタム要素のオーバーレイ（draw_flexible）

狭いサイドバーと広いメインコンテンツ領域の組み合わせや、コンパクトなヘッダー行など、列や行に非対称な比率が必要な場合は、明示的な column_widths・column_margins・row_heights・row_margins を指定して grid.draw_flexible(...) を使用します。各セルの位置は xy から決定論的に算出できるため、任意のセル内に標準のアイコンや図形を正確に重ねて配置することも可能です。

grid.add(position=(1, 1), width=1, height=1, text="      Metrics Store", style=Styles.Neutral.patch(shape_r=1.5))

4. 座標系とインデックスの規則

ページ冒頭の図解に示されているとおり、座標とインデックスは以下の規則に従います。

  • 左下アンカー (x, y): draw() または draw_flexible() に渡す xy 座標は、グリッド全体の左下角を指定します（デフォルトの align="bottom_left" の場合）。
  • 0 始まりのボトムアップ行インデックス:
    • column_start = 0 は最左列を表し、右方向へ増加します（0 〜 num_column - 1）。
    • row_start = 0 は最下行を表し、上方向へ増加します（0 〜 num_row - 1）。
  • セルスパン（複数セル結合）: grid.add(position=(col, row), width=w, height=h) は、右方向へ w 列（col 〜 col + w - 1）、上方向へ h 行（row 〜 row + h - 1）にまたがってセルを結合します。

5. API リファレンス

コンストラクタ

GridLayout(
    *,
    num_column: int,
    num_row: int,
    style: Style,
    text_style: Style,
)

メソッドとプロパティ

  • add(position: tuple[int, int], width: int, height: int, *, style: Style | None = None, text: str = "", text_style: Style | None = None, show: bool = True) -> GridItem: position=(column_start, row_start) を起点に width 列・height 行にまたがるグリッドカードを登録し、変更可能な GridItem（position, width, height, style, text, text_style, show）を返します。show=False を設定すると、マトリクス全体のレイアウトを維持したまま該当セルのみを非表示にします。
  • grid.items -> list[GridItem]: 登録済みのすべての GridItem インスタンスのリスト（position: tuple[int, int], width: int, height: int, style: Style, text: str, text_style: Style, show: bool）を返します。draw() の呼び出し前や複数回の呼び出し間でプロパティを事後変更できます。
  • draw(xy: tuple[float, float], width: float, height: float, margin: float, outer_style: Style | None = None, scale: float = 1.0) -> None: 均等な列幅と行高さを margin の間隔で区切ってグリッドを描画します。outer_style を指定した場合、外側を囲むコンテナ矩形を描画し、外周にも margin 分の内側パディングを追加します。
  • draw_flexible(xy: tuple[float, float], column_widths: list[float], column_margins: list[float], row_heights: list[float], row_margins: list[float], outer_style: Style | None = None, scale: float = 1.0) -> None: 明示的な列幅（len == num_column）、列マージン（len == num_column + 1）、行高さ（len == num_row）、および行マージン（len == num_row + 1）を指定してグリッドを描画します。
