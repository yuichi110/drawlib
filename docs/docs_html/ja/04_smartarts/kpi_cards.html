KpiCards（KPI カード）

KpiCards コンポーネント（別名 KpiCard）は、視認性の高いヘッドライン数値やステータストークン（metric）と、構造化されたカードタイトル（text）・補足説明（description）・オプションのベクター icon・アクセント表示（"left_pill"、"top_bar"、"none"）を組み合わせた指標ハイライトカードを描画します。 垂直スタック（columns=1）と複数列ダッシュボードグリッド（columns=2..N）の両方に対応しており、SLA 目標、ベンチマーク結果の要約、エグゼクティブ向け KPI サマリーに最適です。

1. 基本概念と基本的な使い方

KpiCards（別名 KpiCard）は .add(...) を通じて視認性の高いヘッドライン数値（metric）とタイトル・説明文・アイコンを組み合わせ、デフォルトで左下角 (x, y)（align="center" の場合は中央）を基準に配置します。"left_pill"・"top_bar"・"none" のアクセント表示とともに、左右分割型の left_column と中央積み上げ型の top_stack を切り替えられるほか、columns=1 の縦スタックから複数列グリッドへの展開、個々の .items[i] セルのスタイル変更や非表示化に対応しています。

def draw_step_bar(active_part: int) -> None:
    """Draw top 4-part progress bar (active_part is 1..4)."""
    pill_w = 31.0
    pill_h = 7.4
    gap = 2.0
    start_x = 4.0 + pill_w / 2.0
    cy = 75.2

    for idx, (label, sublabel) in enumerate(PART_ITEMS, start=1):
        cx = start_x + (idx - 1) * (pill_w + gap)
        if idx > 1:
            prev_cx = cx - (pill_w + gap)
            line(
                (prev_cx + pill_w / 2.0 + 0.2, cy),
                (cx - pill_w / 2.0 - 0.2, cy),
                style=Styles.PrimaryBold if idx <= active_part else Styles.MutedThin,
            )

        if idx == active_part:
            st = Styles.PrimaryFlat.patch(shape_r=1.4)
            tst = Styles.WhiteBold.patch(text_size=10.3)
            sub_tst = Styles.White.patch(text_size=9.5)
        elif idx < active_part:
            st = Styles.PrimaryNeutral.patch(shape_r=1.4, shape_line_width=1.1)
            tst = Styles.PrimaryBold.patch(text_size=10.3)
            sub_tst = Styles.Primary.patch(text_size=9.5)
        else:
            st = Styles.Neutral.patch(shape_r=1.4, shape_line_width=1.1)
            tst = Styles.MutedBold.patch(text_size=10.3)
            sub_tst = Styles.Muted.patch(text_size=9.5)

        rectangle((cx, cy), width=pill_w, height=pill_h, style=st)
        text((cx, cy + 1.35), label, style=tst)
        text((cx, cy - 1.55), sublabel, style=sub_tst)

def draw_geometry_studio(param_badge: str, footer_caption: str) -> tuple[float, float]:
    """Draw right geometry lab shell, inner coordinate sheet with subtle grid, and footer."""
    x0, w = 70.0, 64.0
    cx = x0 + w / 2.0
    top_y = 63.2
    header_h = 5.4
    body_h = 59.6

    rectangle((cx, top_y + header_h / 2.0), width=w, height=header_h, style=PANE_HEADER)
    phosphor.ruler((x0 + 3.6, top_y + header_h / 2.0), width=3.4, style=Styles.Primary)
    text(
        (x0 + 6.5, top_y + header_h / 2.0),
        "Live Geometry & Guides",
        style=Styles.DarkBold.patch(text_size=10.2, halign="left"),
    )
    text(
        (x0 + w - 2.6, top_y + header_h / 2.0),
        param_badge,
        style=Styles.PrimaryBold.patch(text_size=9.6, halign="right"),
    )

    rectangle((cx, 3.6 + body_h / 2.0), width=w, height=body_h, style=STUDIO_BODY)

    sheet_cx, sheet_cy = cx, 36.2
    sheet_w, sheet_h = 54.0, 40.0
    sx0, sy0 = sheet_cx - sheet_w / 2.0, sheet_cy - sheet_h / 2.0
    rectangle(
        (sheet_cx, sheet_cy),
        width=sheet_w,
        height=sheet_h,
        style=Styles.Neutral.patch(
            shape_fill_color=(255, 255, 255),
            shape_line_color=(180, 194, 214),
            shape_line_width=1.2,
        ),
    )
    g_st = Styles.MutedThin.patch(line_color=(232, 238, 246), line_width=0.8)
    for gx in range(1, 6):
        vx = sx0 + gx * (sheet_w / 6.0)
        line((vx, sy0), (vx, sy0 + sheet_h), style=g_st)
    for gy in range(1, 5):
        vy = sy0 + gy * (sheet_h / 5.0)
        line((sx0, vy), (sx0 + sheet_w, vy), style=g_st)

    rectangle(
        (cx, 8.4),
        width=59.2,
        height=5.2,
        style=Styles.Neutral.patch(
            shape_fill_color=(255, 255, 255),
            shape_line_color=(203, 213, 225),
            shape_line_width=1.1,
            shape_r=2.4,
        ),
        text=footer_caption,
        text_style=Styles.DarkBold.patch(text_size=9.8),
    )
    return sheet_cx, sheet_cy


def draw_sub_pills(scx: float, labels: list[str], active_idx: int) -> None:
    """Draw 3-step tracker pills near the top of the studio sheet."""
    pw, ph, pgap = 16.2, 4.2, 0.9
    p_start = scx - (3 * pw + 2 * pgap) / 2.0 + pw / 2.0
    for idx, lbl in enumerate(labels):
        px = p_start + idx * (pw + pgap)
        if idx == active_idx:
            pst = Styles.PrimaryFlat.patch(shape_r=1.2)
            ptst = Styles.WhiteBold.patch(text_size=9.5)
        elif idx < active_idx:
            pst = Styles.PrimaryNeutral.patch(shape_r=1.2, shape_line_width=1.0)
            ptst = Styles.PrimaryBold.patch(text_size=9.5)
        else:
            pst = Styles.Neutral.patch(shape_r=1.2, shape_line_width=1.0)
            ptst = Styles.Muted.patch(text_size=9.5)
        rectangle((px, 52.0), width=pw, height=ph, style=pst, text=lbl, text_style=ptst)

  • ヘッドライン指標とアンカー（xy, align）: .add(metric, text, description, icon=...) で KPI カードを登録し、デフォルトの左下 xy（align="bottom_left"）または中央（align="center"）を基準に (width, height) 領域内へ描画します。
  • 内部レイアウトとアクセント（metric_layout, accent_position）: 左右分割型の行カードには metric_layout="left_column" と accent_position="left_pill"、中央揃えのグリッドタイルには "top_stack" と "top_bar"、枠線のみのミニマルなカードには "none" を組み合わせます。
  • 縦スタックから複数列グリッドまで（columns, spacing, metric_width_ratio）: 縦積みの SLO スタックには columns=1、行優先のダッシュボードグリッドには columns=2..N を指定し、カード間隔 spacing や左列幅比率 metric_width_ratio（0.1〜0.7）を調整できます。
  • カード単位のセマンティックアラートとスロット維持（.items[i], .show）: しきい値超過のアラート強調には kpi.items[i].accent_style と metric_style を個別に上書きし、他のグリッドセルの位置を固定したままカードを非表示にするには kpi.items[i].show = False を設定します。

2. 左列レイアウトによる垂直メトリクススタック（metric_layout="left_column"）

metric_layout="left_column"（デフォルト）では、各カードの左列（metric_width_ratio）に大きなヘッドライン指標を配置し、右側にカードタイトル（text）と説明文（description）を配置します。オプションのベクター icon はメトリクス領域内に並べて描画されます。

4. レイアウトモードと座標ジオメトリ

  • 左下アンカーまたは中央アンカー（xy, align）: KpiCards.draw(xy=(x, y), width=W, height=H, columns=C, align="bottom_left") は、全体のバウンディングボックスの左下角を (x, y) に固定し、右方向（+x）に W 単位、上方向（+y）に H 単位の領域へ展開します。align="center" の場合はグリッド全体を (x, y) の中央に配置します。
  • 行優先（Row-Major）のグリッド配置順: columns > 1 の場合、各要素は上の行から下の行へ、左から右へ順に配置されるため、items[0] はバウンディングボックスの左上に配置されます。
  • アクセント位置（accent_position）:
    • "left_pill" （デフォルト）: 各カードの左端内側に縦方向の角丸アクセントバーを描画します（accent_style が必須）。
    • "top_bar": 各カードの上端に沿って横方向のアクセントバーを描画します（accent_style が必須）。
    • "none": アクセントバーを省略し、枠線のみのシンプルなカードを描画します。
  • メトリクスレイアウト（metric_layout）:
    • "left_column" （デフォルト）: 各カードを左右に分割し、左側のメトリクス領域（metric_width_ratio、デフォルト 0.28）と右側のタイトル・説明文領域に配置します。columns=1 や横幅の広い columns=2 レイアウトに最適です。
    • "top_stack": カード上半分の中央に大きなメトリクスを配置し、その下の中央にタイトル（text）と説明文（description）を縦積みで配置します。コンパクトな複数列グリッド（columns=2 または 3）に最適です。

5. API リファレンス

コンストラクタ

KpiCards(
    *,
    style: Style,
    metric_style: Style,
    text_style: Style,
    description_style: Style | None = None,
    accent_style: Style | None = None,
    icon_style: Style | None = None,
    accent_position: Literal["left_pill", "top_bar", "none"] = "left_pill",
    metric_layout: Literal["left_column", "top_stack"] = "left_column",
    metric_width_ratio: float = 0.28,
    spacing: float = 3.0,
)

（エイリアス: drawlib.smartarts からは KpiCards の別名として KpiCard もエクスポートされています。）

メソッドとプロパティ

  • add(metric: str, text: str, description: str = "", *, style: Style | None = None, metric_style: Style | None = None, text_style: Style | None = None, description_style: Style | None = None, accent_style: Style | None = None, icon: Callable | None = None, icon_style: Style | None = None, show: bool = True) -> KpiCardItem: メトリクスカード項目（text がカードの主タイトル）を登録し、変更可能な KpiCardItem を返します。item.show = False を設定すると、他のすべてのカードのグリッド位置とサイズを固定したまま、そのカードの描画をスキップします。
  • kpicards.items -> list[KpiCardItem]: スタイル・テキスト・表示状態を事後変更するための、登録済み KpiCardItem インスタンスのリストを返します。
  • draw(xy: tuple[float, float], width: float = 90.0, height: float = 60.0, *, columns: int = 1, align: Literal["bottom_left", "center"] = "bottom_left", scale: float = 1.0) -> Self: 左下角 xy（align="center" の場合は中央 xy）を基準とする (width, height) のバウンディングボックス内に、表示対象のすべてのカードを描画します。
