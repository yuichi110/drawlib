Pyramid（ピラミッド図）

Pyramid コンポーネントは、三角形の頂点を冠した台形の階層構造を描画します。 標準的な上向きピラミッド、逆ピラミッド型ファネル、横向き配置、および段ごとのカスタム高さ指定に対応しており、ソフトウェアテストピラミッド、DIKW 知識階層モデル、多層防御ティア、コンバージョンファネルの図解に最適です。

1. 基本概念と基本的な使い方

Pyramid は .add(...) によって段階的な階層構造やコンバージョンファネルを構築し、デフォルトでバウンディングボックスの左下角 xy=(x, y)（align="center" の場合は中央）を基準に配置します。広い底辺の向きを 4 方向（"bottom", "top", "left", "right"）から選択できるほか、"vertex_to_base" と "base_to_vertex" の並び順切り替え、draw_flexible(...) による段ごとの高さ指定、他の段の形状を保ったまま .items[i] を非表示にする操作に対応しています。

def draw_step_bar(active_part: int) -> None:
    """Draw top 4-part progress bar (active_part is 1..4)."""
    pill_w = 31.0
    pill_h = 7.4
    gap = 2.0
    start_x = 4.0 + pill_w / 2.0
    cy = 75.2

    for idx, (label, sublabel) in enumerate(PART_ITEMS, start=1):
        cx = start_x + (idx - 1) * (pill_w + gap)
        if idx > 1:
            prev_cx = cx - (pill_w + gap)
            line(
                (prev_cx + pill_w / 2.0 + 0.2, cy),
                (cx - pill_w / 2.0 - 0.2, cy),
                style=Styles.PrimaryBold if idx <= active_part else Styles.MutedThin,
            )

        if idx == active_part:
            st = Styles.PrimaryFlat.patch(shape_r=1.4)
            tst = Styles.WhiteBold.patch(text_size=10.3)
            sub_tst = Styles.White.patch(text_size=9.5)
        elif idx < active_part:
            st = Styles.PrimaryNeutral.patch(shape_r=1.4, shape_line_width=1.1)
            tst = Styles.PrimaryBold.patch(text_size=10.3)
            sub_tst = Styles.Primary.patch(text_size=9.5)
        else:
            st = Styles.Neutral.patch(shape_r=1.4, shape_line_width=1.1)
            tst = Styles.MutedBold.patch(text_size=10.3)
            sub_tst = Styles.Muted.patch(text_size=9.5)

        rectangle((cx, cy), width=pill_w, height=pill_h, style=st)
        text((cx, cy + 1.35), label, style=tst)
        text((cx, cy - 1.55), sublabel, style=sub_tst)

def draw_geometry_studio(param_badge: str, footer_caption: str) -> tuple[float, float]:
    """Draw right geometry lab shell, inner 54x40 coordinate sheet, and footer."""
    x0, w = 70.0, 64.0
    cx = x0 + w / 2.0
    top_y = 63.2
    header_h = 5.4
    body_h = 59.6

    rectangle((cx, top_y + header_h / 2.0), width=w, height=header_h, style=PANE_HEADER)
    phosphor.ruler((x0 + 3.6, top_y + header_h / 2.0), width=3.4, style=Styles.Primary)
    text(
        (x0 + 6.5, top_y + header_h / 2.0),
        "Live Geometry & Guides",
        style=Styles.DarkBold.patch(text_size=10.2, halign="left"),
    )
    text(
        (x0 + w - 2.6, top_y + header_h / 2.0),
        param_badge,
        style=Styles.PrimaryBold.patch(text_size=9.6, halign="right"),
    )

    rectangle((cx, 3.6 + body_h / 2.0), width=w, height=body_h, style=STUDIO_BODY)

    sheet_cx, sheet_cy = cx, 35.0
    sheet_w, sheet_h = 54.0, 40.0
    sx0, sy0 = sheet_cx - sheet_w / 2.0, sheet_cy - sheet_h / 2.0
    rectangle(
        (sheet_cx, sheet_cy),
        width=sheet_w,
        height=sheet_h,
        style=Styles.Neutral.patch(
            shape_fill_color=(255, 255, 255),
            shape_line_color=(180, 194, 214),
            shape_line_width=1.2,
        ),
    )
    g_st = Styles.MutedThin.patch(line_color=(232, 238, 246), line_width=0.8)
    for gx in range(1, 6):
        vx = sx0 + gx * (sheet_w / 6.0)
        line((vx, sy0), (vx, sy0 + sheet_h), style=g_st)
    for gy in range(1, 5):
        vy = sy0 + gy * (sheet_h / 5.0)
        line((sx0, vy), (sx0 + sheet_w, vy), style=g_st)

    rectangle(
        (cx, 8.6),
        width=59.2,
        height=5.2,
        style=Styles.Neutral.patch(
            shape_fill_color=(255, 255, 255),
            shape_line_color=(203, 213, 225),
            shape_line_width=1.1,
            shape_r=2.4,
        ),
        text=footer_caption,
        text_style=Styles.DarkBold.patch(text_size=9.8),
    )
    return sheet_cx, sheet_cy


def draw_sub_pills(scx: float, labels: list[str], active_idx: int) -> None:
    """Draw 3-step tracker pills above the studio coordinate sheet."""
    pw, ph, pgap = 17.2, 4.0, 1.2
    p_start = scx - (3 * pw + 2 * pgap) / 2.0 + pw / 2.0
    for idx, lbl in enumerate(labels):
        px = p_start + idx * (pw + pgap)
        if idx == active_idx:
            pst = Styles.PrimaryFlat.patch(shape_r=1.2)
            ptst = Styles.WhiteBold.patch(text_size=9.5)
        elif idx < active_idx:
            pst = Styles.PrimaryNeutral.patch(shape_r=1.2, shape_line_width=1.0)
            ptst = Styles.PrimaryBold.patch(text_size=9.5)
        else:
            pst = Styles.Neutral.patch(shape_r=1.2, shape_line_width=1.0)
            ptst = Styles.Muted.patch(text_size=9.5)
        rectangle((px, 59.1), width=pw, height=ph, style=pst, text=lbl, text_style=ptst)

  • 段階的なティア構築とアンカー（xy, align）: .add(text, style=...) で階層スライスを順に追加し、margin で区切られた width × height 領域内に描画します（デフォルトの align="bottom_left" では左下角基準、align="center" では中央基準）。
  • 4 つの底辺方向（direction）: direction は広い底辺を配置する辺を指定します。"bottom"（上向き階層）、"top"（逆ピラミッド／ファネル）、"left"（底辺が左・頂点が右）、"right"（底辺が右・頂点が左。このとき width が縦方向の底辺幅、height が横方向の高さになります）を選択できます。
  • 頂点基準と底辺基準の並び順（order）: デフォルトの order="vertex_to_base" は最初の .add() 要素を三角形の頂点に配置します。order="base_to_vertex" を渡すと最初の .add() 要素が広い底辺から始まるため、direction="top" と組み合わせたトップダウンのファネル表現に最適です。
  • 可変ティア高さとスロット維持の .show（draw_flexible, .items[i]）: draw_flexible(..., item_heights=[...], margins=[...])（底辺から頂点への順）で段ごとの高さを個別に指定でき、pyr.items[i].show = False を設定すれば他の段の形状をずらさずに特定の段を非表示にできます。

4. ジオメトリ・向き・並び順の規則

ページ冒頭の図解に示されているとおり、ジオメトリと並び順は以下の規則に従います。

  • アンカー基準位置（align）: draw() または draw_flexible() に渡す xy 座標は、ピラミッド全体のバウンディングボックスの左下角（align="bottom_left"、デフォルト）または中央（align="center"）を指定します。
  • 配置方向（direction）:
    • "bottom" （デフォルト）: 上向きピラミッド（広い底辺が下、頂点が上向き）。
    • "top": 逆ピラミッド／ファネル（広い底辺が上、頂点が下向き）。
    • "left": 横向きピラミッド（広い底辺が左、頂点が右向き）。
    • "right": 横向きピラミッド（広い底辺が右、頂点が左向き）。
  • 要素の並び順（order）:
    • "vertex_to_base" （デフォルト）: 最初に追加した要素が三角形の頂点に配置され、最後に追加した要素が広い底辺に配置されます。
    • "base_to_vertex": 最初に追加した要素が広い底辺に配置され、最後に追加した要素が三角形の頂点に配置されます。

5. API リファレンス

コンストラクタ

Pyramid(
    *,
    style: Style,
    text_style: Style,
)

メソッドとプロパティ

  • add(text: str, *, style: Style | None = None, text_style: Style | None = None, show: bool = True) -> PyramidItem: ピラミッドに段（ティア）を追加し、変更可能な PyramidItem（style, text, text_style, show）を返します。show=False を設定すると、その段のスライス形状を保持したまま非表示にするため、他の段の位置がずれることはありません。
  • pyramid.items -> list[PyramidItem]: 登録済みのすべての PyramidItem インスタンスのリスト（style: Style, text: str, text_style: Style, show: bool）を返します。draw() の呼び出し前や複数回の呼び出し間でプロパティを事後変更できます。
  • draw(xy: tuple[float, float], width: float, height: float, margin: float, direction: Literal["bottom", "top", "left", "right"] = "bottom", order: Literal["vertex_to_base", "base_to_vertex"] = "vertex_to_base", align: Literal["bottom_left", "center"] = "bottom_left", scale: float = 1.0) -> None: margin の間隔で均等な高さに分割したピラミッドを、align に従って xy を基準に描画します。必要に応じて xy を基点とした比例スケーリング（scale）も適用できます。
  • draw_flexible(xy: tuple[float, float], width: float, item_heights: list[float], margins: list[float], direction: Literal["bottom", "top", "left", "right"] = "bottom", order: Literal["vertex_to_base", "base_to_vertex"] = "vertex_to_base", align: Literal["bottom_left", "center"] = "bottom_left", scale: float = 1.0) -> None: 段ごとの明示的な高さ（len(item_heights) == len(items)）と段間マージン（len(margins) == len(items) - 1）を指定してピラミッドを描画します。item_heights は底辺（ベース）から頂点（バーテックス）へ向かう順序で指定する点に注意してください。
