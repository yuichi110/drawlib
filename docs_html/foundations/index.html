Foundations Guide

The Foundations section covers core drawing concepts and fundamental building blocks in Drawlib.

Foundation Modules

  • Canvas & Dimensions: Coordinate space, canvas configuration, resolution, and exports.
  • Coordinates & Alignment: Cartesian coordinate space, geometric center anchors, and alignment transforms.
  • Shapes Overview: All 21 shape primitives, dimensions, and path vector shapes.
  • Circle-like Shapes: Circles, donuts, wedges, fans, regular polygons, and stars.
  • Rectangle-like Shapes: Rectangles, ellipses, arcs, parallelograms, rhombuses, and trapezoids.
  • Block Arrow Shapes: Straight, L-shaped, U-turn, arc, and polyline block arrows.
  • Shape Styling: Fills, borders, line styles, opacity, and embedded text styling.
  • Lines Guide: Straight lines, curved splines, Bezier curves, and arc lines.
  • Line Styles: Width, color, dash styles, and arrowhead markers.
  • Text Guide: Horizontal and vertical text, font registration, alignment, and rotation.
  • Icons Guide: Phosphor icons, Google Cloud Platform (GCP) official architecture icons, and badges.
  • Images Guide: Image embedding, PIL Image integration, Dimage caching, and filters.
  • Dimage Image Processing: Image caching, transformation effects (resize, crop, blur, mosaic, colorize), and format conversions.
  • Coding Best Practices: Layout patterns, center alignment strategies, and clean illustration code.
