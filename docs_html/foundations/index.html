Foundations Guide

The Foundations section covers core drawing concepts and fundamental building blocks in Drawlib.

Foundation Modules

  • Canvas & Coordinate System: Coordinate space, resolution (DPI), grid overlays, and file exports.
  • Shapes Guide: Circles, rectangles, polygons, stars, arrows, and shape styling.
  • Lines Guide: Straight lines, curved splines, polyline connectors, and line styling.
  • Text Guide: Text rendering, font registration, alignment, and typography styling.
  • Images Guide: Image embedding, cropping, aspect ratios, and filter effects.
  • Icons Guide: Phosphor icons, icon badges, and icon styling.
