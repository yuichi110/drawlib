Welcome to Chapter 5: 5 Archetypes & Publishing.
Up to this point, we have explored Drawlib's Python drawing primitives, SmartArts, Charts, Diagrams, and Graph layout solvers.
Now we zoom out from individual illustrations to full project publishing: how a single unified compiler transforms Markdown and Python source repositories into five purpose-built project archetypes—documentation portals (`site`), API reference dictionaries (`catalog`), multi-chapter whitepapers (`doc`), interactive 16:9 slide decks (`slide`), and standalone visual asset suites (`images`)—complete with vector PDF and native Microsoft Office (`.docx` and `.pptx`) exports.
